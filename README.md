# Project Ire

Project Ire is an LLM-powered autonomous malware classification system. Designed to classify software without context, Project Ire replicates the gold standard in malware analysis through reverse engineering. It streamlines a complex, expert-driven process, making large-scale malware detection faster & more consistent.
